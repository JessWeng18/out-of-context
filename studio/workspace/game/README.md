# Out of Context: Escape from Weng Manor

A short escape game that teaches you about LangChain's Deep Agents Harness. You wake up in a locked manor with Polly, a Deep Agent bird, and find the 11-letter password to get out.

## Play

1. Open `index.html` in a browser (Chrome works best).
2. You need an internet connection and sound on.
3. Press any key to start.

## Controls

| Key | Action |
|---|---|
| Arrow keys | Walk, move through menus |
| Z | Look, talk, continue, choose |
| X | Back, close |
| C | Deep Agents cards you've unlocked |
| H | Ask Polly for a hint |
| 1-4 | Use an item from your inventory |
| M | Sound on or off |
